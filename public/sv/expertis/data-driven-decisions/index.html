Talaruppdrag inom datadrivet beslutsfattande

Hur organisationer använder Big Data i praktiken.

Nästan alla organisationer samlar in mer data än någonsin, men få upplever att besluten har blivit bättre. Rapporterna blir fler, medan frågan om vem som faktiskt ändrar kurs efter att ha läst dem förblir obesvarad. Därför lockar föreläsare som kan visa ett beslut som verkligen styrdes av data: vilken fråga man ställde, hur underlaget togs fram, var siffrorna ledde fel och hur ledningen till slut började lita på analysen. Ärlighet om dålig datakvalitet är ofta det publiken minns.

Universitet och handelshögskolor bjuder in praktiker till kurser i analys, statistik och ekonomistyrning, och studentföreningar inom data och ekonomi ordnar gärna case-kvällar. Meetups samlar analytiker som vill ha tekniskt djup, medan branschseminarier och webbinarier riktar sig till chefer. Anpassa nivån efter publiken och förklara resonemanget bakom siffrorna i stället för att visa så många diagram som möjligt.

Vanliga frågor

Måste jag kunna statistik på djupet?

Inte för alla publiker. Chefsseminarier vill ofta höra hur data användes i beslut, medan meetups och kurser i analys förväntar sig mer metod.

Kan jag visa riktiga data från min verksamhet?

Bara om du har tillstånd. Anonymiserade eller påhittade exempel fungerar ofta lika bra för att visa resonemanget.

Måste jag vara utvecklare för att föreläsa om AI?

Nej. Arrangörer vill också höra personer som har lett AI-projekt, köpt verktyg, hanterat riskerna eller ändrat hur ett team arbetar. Erfarenhet väger tyngre än kod.
